¿Qué es exactamente la "vista mobile"? Esto define toda la arquitectura del plan.

Voy a leer la matriz v2 y el código del server antes de diseñar nada.

La matriz v2 deja claro que la vista mobile es una lista de sesiones con chips, no una versión reducida de la web. O sea:

  • el server ya expone el listado paginado, con limit y offset
  • el cliente no necesita un WebView ni un runtime de React
  • el estado global vive en el provider, no en un store duplicado
